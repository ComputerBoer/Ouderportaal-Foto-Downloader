# Ouderportaal – Foto Downloader

Dit programma is ontwikkeld om eenvoudig en snel meerdere foto’s uit het Ouderportaal te downloaden.  
Na een recente update was dit niet langer direct mogelijk via het portaal zelf, daarom heb ik dit hulpmiddel in mijn vrije tijd gebouwd.

Je mag het programma gebruiken zoals het is.  
**Ik voeg geen functionaliteit toe op verzoek.**

Het programma maakt gebruik van dezelfde gegevens die je normaal invoert wanneer je inlogt via een webbrowser (Edge, Chrome, Safari of Firefox).  
Als het Ouderportaal wijzigingen doorvoert, kan het zijn dat dit programma niet meer werkt. 

Aan het gebruik van dit programma kunnen geen rechten worden ontleend en is geheel op eigen risico.

## Installatie

1. Instaleer python (https://www.python.org/). Getest met Python 3.14
2. Voer Install.bat uit

## Gebruik

1. Voer Run.bat uit
2. Voer je Organisatie in
3. Voer je gebruikersnaam van het Ouderportaal in.  
4. Voer je wachtwoord in.  
5. Vul het aantal dagen in waarvan je foto’s wilt downloaden (Het programma begint bij de meest recente dag en gaat daarna terug in de tijd.)
